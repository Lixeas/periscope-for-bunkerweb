# Brand

The Periscope logo: a periscope rising from a blockhouse. Its head draws a **P**, the counter of the P is the lens, and the teal pupil looks right, out of the bunker. It is the nod to BunkerWeb: from inside the bunker you watch without being exposed, and you only watch (read-only). Construction and rules: [DESIGN.md, Brand mark](../../DESIGN.md#brand-mark).

| File | Use |
|---|---|
| `periscope-mark-light.svg` | Mark on a light ground (ink #17251f, pupil #136f5c). |
| `periscope-mark-dark.svg` | Mark on a dark ground (ink #e7f1ec, pupil #45c9a2). |
| `periscope-mark-mono.svg` | One colour (black), for print, stamps and embroidery. |
| `periscope-lockup-light.svg`, `periscope-lockup-dark.svg` | Mark + `periscope` wordmark + "for BunkerWeb". |
| `periscope-social.svg`, `periscope-social.png` | 1280 x 640 card (GitHub social preview, links). |

The favicon set (`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`) is in `src/periscope/web/static/`. Text in these files is outlined (Office Code Pro and Switzer, both shipped in `web/static/fonts`), so they render without the fonts.

Keep clear space of at least a quarter of the mark's height around it, and do not use it below 16px. Independent project, not affiliated with Bunkerity: never pair the mark with Bunkerity's logo or colours.
